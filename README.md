# 工地考勤记账小程序

一个基于 **微信小程序 + 微信云开发** 的轻量级工地管理工具，面向包工头、班组长和工地工人，解决 **员工建档、项目管理、借支记录、月度考勤填报、月度公示核对** 等核心问题。

该项目同时包含前端小程序代码与云函数实现，适合作为：

- 微信小程序实战项目
- 劳务/工地管理场景作品集
- 产品反推与 PRD 学习案例

## 项目亮点

- 双角色设计：管理员 / 员工
- 员工微信绑定，减少账号体系成本
- 按月汇总的考勤填报与公示能力
- 借支记录、图片凭证、疑问反馈闭环
- 支持员工、考勤、借支 Excel 导出
- 已沉淀三份迭代版 PRD，适合学习和面试讲解

## 功能概览

### 管理员端

- 管理员邀请码登录
- 员工管理
  - 新增/编辑员工
  - 查看绑定状态
  - 邀请员工绑定微信
  - 导出员工信息
- 项目管理
  - 新增/编辑项目
  - 标记项目完工
- 借支管理
  - 记录借支
  - 上传借支凭证
  - 修改/删除借支记录
  - 导出借支明细
- 考勤管理
  - 查看月度填报进度
  - 查看未填报名单
  - 查看考勤明细
  - 导出考勤数据
  - 生成月度公示报表
- 疑问处理
  - 查看员工借支疑问
  - 直接修改对应借支
  - 标记处理完成

### 员工端

- 绑定本人员工身份
- 填报上月考勤
- 查看历史考勤记录
- 查看个人借支记录
- 对借支发起疑问反馈
- 编辑个人资料

## 适用场景

适用于小型施工团队、劳务班组、熟人协作型工地管理场景，尤其适合以下需求：

- 需要快速上线，不想搭建复杂后台
- 员工普遍使用微信，适合小程序入口
- 管理重点集中在考勤、借支、公示核对
- 希望低成本完成基础数字化

## 技术方案

- 前端：微信小程序原生开发
- 后端：微信云开发
- 数据层：云数据库
- 文件能力：云存储
- 服务能力：云函数

## 核心页面

### 管理端

| 页面 | 功能说明 |
|------|----------|
| 登录页 | 邀请码验证登录 |
| 员工列表 | 增删改查、导出、邀请绑定 |
| 项目列表 | 项目增删改、完工标记 |
| 借支记录 | 借支新增/编辑/删除、凭证上传 |
| 考勤填报 | 月度进度监控、未填报提醒 |
| 考勤报表 | 月度汇总、导出、公示发布 |
| 疑问处理 | 员工反馈、在线修改 |

### 员工端

| 页面 | 功能说明 |
|------|----------|
| 绑定页 | 扫码绑定或账号密码绑定 |
| 我的考勤 | 月度考勤直报、历史记录 |
| 我的借支 | 借支明细、疑问发起 |
| 个人中心 | 资料编辑、退出登录 |

## 云函数列表

| 云函数 | 功能 |
|--------|------|
| login | 登录验证 |
| bindWorker / bindWorkerWechat | 员工绑定 |
| getWorkers / getProjects | 数据查询 |
| addAdvance / deleteWorkerCascade | 借支管理 |
| submitAttendance / getAttendanceSummary | 考勤管理 |
| exportAttendance / exportAdvance / exportWorkers | 数据导出 |
| sendSubscribeMessage | 订阅消息推送 |

## 本地开发

1. 注册微信小程序账号，开通云开发
2. 克隆本仓库
3. 在微信开发者工具中导入 `miniprogram` 目录
4. 部署云函数到对应环境
5. 配置云开发环境 ID
